# Media asset list

Do not commit large raw recordings to Git. Store originals in a backed-up media
folder and commit only optimized stills when useful.

Required:

- `cover-1920x1080.png` — one strong canvas, short title, readable at thumbnail.
- `product-youversion.png` — licensed version selector plus passage.
- `product-ai.png` — canvas-aware DeepSeek request and visible result.
- `product-collaboration.png` — two participants or shared update.
- `architecture-1920x1080.png` — simplified version of `ARCHITECTURE.md`.
- `demo-final.mp4` — 1080p, H.264, at most 3:00; upload to YouTube.

Cover guidance: use one focal canvas, a human-scale problem, and no more than
six words: **Scripture, native to creation.**
